- A fashion e-commerce website for a clothing designer, built from scratch as a hands-on MERN stack learning project.
- **Current stage:** static homepage with semantic HTML, CSS (flexbox layout, Google Fonts, hover effects) and first JavaScript interactions.
- **Planned stack:** MongoDB, Express, React and Node.js.
- **Planned features:** product listings, wishlist, cart, user accounts, checkout, and an admin panel for the designer to manage her collections.
- **Run locally:** open the folder in VS Code and launch `index.html` with the Live Server extension.
